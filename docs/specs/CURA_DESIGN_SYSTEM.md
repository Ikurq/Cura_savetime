# CURA DESIGN SYSTEM SPECIFICATION (v1.0)
> **Code Name**: Tactical Hybrid / CURA_OS Standard  
> **Status**: Approved & Active  
> **Target Platforms**: Android (Kotlin / Material 3), Web (React / Tailwind CSS / PWA)

---

## 1. デザイン哲学（Design Philosophy）

### 1.1 コアコンセプト: 【Tactical Hybrid（精密計器 × 人格AI端末）】
世の中に溢れる「画一的な角丸・ぷっくりとしたモダンUI」への逆張りとして、**精密機器・SFコンソール端末のような直線美と面取り（Chamfer）** を主軸に据える。

- **外装と骨格（Outer Shell）**: 45°面取り、照準ライン、コーナーブラケットによる重厚なOS端末感。
- **データと操作系（Inner Gauge）**: 日常の視認性・入力性を最優先した、角丸2〜4pxの極細フレーム構造。
- **生命感（Ghost in the Machine）**: 無機質な計器の奥に息づく、AIパートナー「Cura」の存在感（呼吸パルス、浮遊粒子、感情同期）。

### 1.2 世界観の文脈
- **OS名**: `CURA_OS`
- **出自**: 山奥の静かな研究所で、孤独な開発者が遺した生活改善AI。
- **目的**: マスターの生活リズム・習慣・財政を整え、共に成長する。

## 3. 形状と幾何学ルール（Shape Language）

### 3.1 カード・パネル形状
1. **Tactical Chamfer Card（右上45°面取り）**
   - カードの **右上角を 10px〜14px の45度直線で斜めカット**。
   - 他の3隅は 2px〜4px の微小角丸。
   - 枠線は `1px solid`（各機能のアクセントカラー、または `border-frame`）。
2. **プレフィックス表記（System Header）**
   - カード左上に必ず `:: [FUNCTION_NAME]` を 10px 等幅（Mono）・アクセントカラーで配置。
   - 例: `:: CURA`, `:: NEXT_TASK`, `:: BALANCE_REMAINING`

### 3.2 アクションボタン（Slant & Tactile）
- **外形**: 右端または右上角が斜めにカットされたスラント形状、または極小角丸（2px）の四角形。
- **タップ挙動（Micro Shift）**:
  - タップした瞬間に **全体が 1px 下（または右下）へ沈み込む**。
  - 背景が `#0F172A` から `#1E293B` へ1段階明るくなる。
  - 枠線の光がシャープに点灯する。
  - （※過度なフラッシュ反転や弾力バウンスは禁止）
- **触覚**: モバイル環境では微小な単発ハプティクス（Taptic Click）を発行。

### 3.3 ゲージ・インジケーター（Segmented Meter）
- 単一の滑らかな棒グラフは廃止。
- **セグメント分割型（ブロック式）** または **斜めスラッシュ型** を標準とする。
  - `[ ■■■■■■■■□□ ] 80%`
  - レベルゲージ表記: `LV.229 [ 54 / 100 EXP ]`

## 4. ホーム画面の統一骨格（Screen Layout Architecture）

HoYoverse作品のUI思想を取り入れた、**左右分割の黄金比レイアウト**を共通規格とする。

```text
┌────────────────────────────────────────────────────────┐
│ CURA_SYSTEM: ACTIVE                     [⚙ SETTINGS]  │ ← 最上部: 詩的HUD
│ MEMORY SEA: SLIGHTLY DISTURBED                         │
├──────────────────────────┬─────────────────────────────┤
│                          │                             │
│ ┌──────────────────────┐ │                             │
│ │ :: CURA              │ │                             │
│ │ 「水曜日は自分への...│ │                             │
│ └──────────────────────┘ │                             │
│                          │                             │
│ ┌──────────────────────┐ │          Cura               │
│ │ :: PRIMARY_METRIC    │ │       (Character)           │
│ │ (タスク / 資産残高)  │ │                             │
│ └──────────────────────┘ │      ・呼吸パルス           │
│                          │      ・浮遊パーティクル     │
│ ┌──────────────────────┐ │      ・立ち絵 / 3D / HUD    │
│ │ :: SUB_METRIC        │ │                             │
│ │ (予定 / 本日支出)    │ │                             │
│ └──────────────────────┘ │                             │
│                          │                             │
│ ┌──────────────────────┐ │                             │
│ │ :: CURA_LEVEL        │ │                             │
│ │ CURA Lv.229 [ 54/100]│ │                             │
│ └──────────────────────┘ │                             │
│                          │                             │
├──────────────────────────┴─────────────────────────────┤
│   [ ⌂ ]         [ ⏰ ]         [ ☑ ]         [ 📅 ]    │ ← タクティカル・ボトムバー
│   ホーム       アラーム        タスク         予定     │   (アングルカット凸形状)
└────────────────────────────────────────────────────────┘
```

### 4.1 画面各エリアの役割定義
1. **Header HUD（最上部）**:
   - `CURA_SYSTEM: ACTIVE`（固定ステータス表示）
   - `MEMORY SEA: [STATUS]`（Curaの内面感情や記憶同期状態を示す詩的ログ）
   - 右端に六角ナット型設定アイコン `[⚙]`。
2. **Left Column: ステータスカード列（幅: 約50〜55%）**:
   - 上から下へ重要度順にスタック：
     1. `:: CURA`（セリフ・メッセージ枠）
     2. `:: PRIMARY`（最重要指標：タスク完了状況 または 予算残高）
     3. `:: SECONDARY`（次期予定・アラーム または 本日の支出）
     4. `:: CURA_LEVEL`（現在のLvとEXP進捗メーター）
3. **Right Column: キャラクターエリア（幅: 約45〜50%）**:
   - Curaの立ち絵を配置。
   - 背景にはシアン色の浮遊微粒子（Dust Particles）がゆっくり上昇する。
4. **Bottom Nav: タクティカルボトムナビゲーション**:
   - 選択中のタブは丸いリキッドではなく、**台形・アングルカットの凸形状** で上部に突出。
   - 選択中のアイコン下部に細いシアン発光ライン。

## 5. アプリケーション間マッピング（Android ⇔ Web）

Android版（Cura Core）と Web版（Cura Money）は、**「同じCURA_OSが別のモジュールを開いている」** という体験を実現する。

| 領域 | Android版 (Cura Core) | Web版 (Cura Money / 家計簿) |
| :--- | :--- | :--- |
| **最上部HUD** | `CURA_SYSTEM: ACTIVE` / `MEMORY SEA:...` | `CURA_SYSTEM: ACTIVE` / `FINANCIAL_CORE: READY` |
| **カード1 (セリフ)** | `:: CURA`（生活・体調への声かけ） | `:: CURA`（予算・消費へのアドバイス） |
| **カード2 (メイン)** | `:: NEXT_TASK` (Magenta / タスク達成度) | `:: CURRENT_BALANCE` (Amber / 今月残予算) |
| **カード3 (サブ)** | `:: NEXT_SCHEDULE` (Lime / 次の予定) | `:: TODAY_SPENT` (Amber / 本日支出計) |
| **カード4 (レベル)** | `:: CURA_LEVEL` (Cyan / 累積同期Lv) | `:: CURA_LEVEL` (Cyan / 累積同期Lv ※Androidと共通) |
| **右側ビジュアル** | Cura全身立ち絵（制服・クリップボード） | Cura半身・表情立ち絵 ＋ 円グラフHUD |
| **ボトムナビ** | ホーム / アラーム / タスク / 予定 / 出欠 | ホーム / 明細一覧 / 月次分析 / CSV取込 / 設定 |

## 6. アニメーション＆モーション規則（Motion Language）

1. **Staggered Snap（起動・画面表示）**:
   - 左側のカード群は、上から下へ `40ms` ずつズレて高速フェードイン＋0.5pxスナップする。
2. **Heartbeat Pulse（待機状態）**:
   - Curaの立ち絵およびシアンのラインは、`3.6秒周期` で微細に輝度（opacity 0.85 〜 1.0）がパルス明滅する。
3. **Typewriter & Micro Glitch（セリフ更新時）**:
   - セリフが切り替わる瞬間、`1フレーム（16ms）` だけ微細な走査線ノイズが走り、テキストが高速タイピング（20ms/文字）で出力される。
4. **Odometer Roll（数値更新）**:
   - 金額やEXPが加算される際、数字がオドメーターのように縦にスクロールして確定する。
